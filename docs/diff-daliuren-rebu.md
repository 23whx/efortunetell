# 大六壬说明（算法来源：热卜金口诀）

> **产品名**：大六壬（UI 不出现「金口诀」）  
> **算法**：`guangming/rebu_re` 热卜参考实现  
> 引擎：`src/lib/paipan/daliuren/` · 页面：`/{locale}/tools/daliuren`

## 四位结构

```text
人元（天干）
贵神（干支 + 神名，如 腾蛇）
将神（干支 + 天将名，如 太冲）
地分（地支）
```

## 核心规则

| 项 | 规则 |
|----|------|
| 四柱 | lunar-javascript 八字（与热卜样例历法一致） |
| 月将 | 默认**中气**换将；可选**交节**（月建六合） |
| 将神 | 月将加时，顺数至地分 + 五鼠遁取干 |
| 贵神 | 日干天乙贵人 + 顺/逆布十二神，取地分上之神；干用五鼠遁 |
| 人元 | 五鼠遁，日干起子布到地分 |
| 贵神类型 | 默认**卯酉区分**（卯–申昼）；可选手动昼/夜 |
| 日空 | 日旬空 |
| 四大空亡 | 子午旬亥子壬癸；寅申旬申酉庚辛 |
| 五动三动 | 干/神/将/方五行生克 |
| 用神 | 阴阳多少简化取贵神或将神 |

## 与 App 对照注意

- 热卜结果页还有完整神煞列表、课体歌诀等，本站 MVP **先出四位+动+空标记**  
- 旺衰用月令五行简表，边界可能与 App 略差  
- 同输入对照：`2024-06-01 09:00` 地分子 → 月将传送(申)、人元戊、贵癸巳腾蛇、将辛卯太冲
