## 结论

1. **日柱**以 lunar-javascript 为准（已纠正错误壬子锚点；1994-10-26=乙酉）。
2. **八字/奇门/六壬四柱**统一走 `src/lib/paipan/calendar`，互相一致。
3. **奇门阴阳遁**：夏至（含）后阴遁、冬至（含）后阳遁；合并 year±1 节气表，避免「冬至」键指向上年导致全季误判阳遁。
4. **真太阳时**：经度时差 + 均时差；E87/E120 专项轮次覆盖八字/奇门/六壬。
5. **万年历**日柱正午锚定；**起名** 3 双字 + 喜用 + 复姓。
6. 奇门三元为拆补简化，与 App 局数可能差一档；历法与遁向以本报告 P0 为准。
