# 八字：易世家 vs 问真 — 差异说明

> 本站实现以 **《易世家》规格** 为主，参看 **《问真八字》** 验收用例与开关语义。  
> 资料目录：`guangming/apk_re`（易世家）、`guangming/pcbz_iwzwh_re`（问真）。

## 1. 已对齐项

| 项 | 本站 | 说明 |
|----|------|------|
| 年柱 | 立春换年 | 与两家子平通行一致 |
| 月柱 | 节换月 + 五虎遁 | 同 |
| 日柱历法 | **lunar-javascript（寿星）** | 与热卜/通行黄历一致。例：`1994-10-26`=**乙酉**。旧版错误「壬子锚点」会错成己卯，已废弃 |
| 晚子时 | `ziMode=late`：23:00 起日柱用次日 | 对应问真默认 `zwz≈true` |
| 时柱 | 五鼠遁 | 同 |
| 藏干 | 易世家表（**未=己丁乙**） | 见下差异 |
| 十神 / 纳音 / 空亡 | 标准表 | 同 |
| 大运顺逆 | 阳男阴女顺，阴男阳女逆 | 同 |
| 起运默认 | 三天折一年（到上一/下一节） | 易世家规格；问真 `pdy=false` 同类 |

## 2. 已知差异 / 可切换项

| 项 | 易世家（本站默认） | 问真 | 用户影响 |
|----|-------------------|------|----------|
| 藏干「未」顺序 | **己、丁、乙** | **己、乙、丁**（zcg） | 中气/余气十神展示顺序不同；本气己相同 |
| 起运 `pdy` | 默认关；UI 可选开 | 默认 `pdy=false`，可开比例法 | 起运年数会不同 |
| 子时实现细节 | late/early 明确开关 | 源码对日柱有特殊 `-1` 索引处理 | 边界 23:30 需对照网站 |
| 节气库 | lunar-javascript | 问真 `GetAdjustedJQ` | 节气边界分钟级可能差 1–2 分钟 → 极少数大运天数差 |
| 真太阳时 | 经度 + 简化均时差 | `zty` 更完整 | 开真太阳时建议对照经纬度 |
| 司令 | 通行人元分野表 | 网站字段可能不同表 | 司令天干边界日可能不同 |

## 3. 验收样例（本站已固化）

### 日柱黄金（2026-07-16 纠正）
- 输入：`1994-10-26 12:00`  
- 期望四柱：`甲戌 甲戌 乙酉 壬午`（日柱 **乙酉**）  
- 对照：lunar-javascript / 热卜 lunar_python；浏览器实测本站页面  
- 说明：资料包里旧 BAZI-01「甲戌日」与通行历（**庚辰日**）不符，属错误锚点，已废弃

### 子时差分
- `1990-01-15 23:30` late → 日柱换次日（乙亥…）  
- same early → 日柱仍甲戌
