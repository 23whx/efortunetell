# 阴盘奇门：易世家 vs 热卜 + 拆补/置闰说明

> 本站实现以 **《易世家》** 规格为主（`guangming/apk_re`），参看 **《热卜》**（`guangming/rebu_re`）。  
> 引擎：`src/lib/paipan/qimen/` · 页面：`/{locale}/tools/qimen`

---

## 1. 拆补 vs 置闰（通俗）

奇门「定局」要先知道：现在是**阳遁还是阴遁**、在哪个**节气段**、属于**上/中/下元**，再查表得到 **几局**。

| | **拆补**（本站默认） | **置闰** |
|--|----------------------|----------|
| 在干什么 | 按节气把日子切成上中下元（常见约各 5 日）；元不够就「借」邻元 | 看符头（甲己日）与节气是否「超神/接气」，必要时整段「置闰」再分元 |
| 比喻 | 按课表固定周次排课，不够就前后周借一天 | 发现校历和节气错位时，整周挪动再排 |
| 影响 | **同一时刻局数可能不同** → 地盘、值符值使全变 | 同上 |
| 本站 | `method=chaibu`：节后 0–4 上元、5–9 中、10+ 下（可运行简化） | UI 可选 `zhirun`，**算法暂与拆补同路径**，待抓包后分叉 |

**建议对照方式：** 固定时间关真太阳 → 先对局数/阴阳遁/旬首/值符值使 → 再对九宫。

## 2. 已实现（易世家主路径）

| 步骤 | 规则 |
|------|------|
| 用时 | 可选真太阳时；四柱走 `calendar/fourPillarsFromLunar`（晚子默认） |
| 阴阳遁 | 冬至（含）后阳，夏至（含）后阴；**合并 year±1 节气表**（lunar-js 单年表「冬至」常为上年，旧实现会夏至后误判阳遁） |
| 历法源 | `calendarSource: lunar`（默认）/ `yishijia`（定局表同；四柱均 lunar，旧 JD 日柱已废弃） |
| 三元 | 拆补简化 5 日一元 |
| 定局 | `yangDunJu` / `yinDunJu` 表 |
| 地盘 | 戊己庚辛壬癸丁丙乙，阳顺阴逆；中五寄坤二 |
| 旬首/值符 | 时旬首 → 六仪 → 地盘原宫星 = 值符 |
| 转盘 | 值符原宫 → 时干宫，星/天盘干/门整体移位 |
| 八神 | 值符在时干宫，阳顺阴逆 |
| 马星/空亡 | 驿马按时支；时空亡落宫 |

九宫屏幕布局：

```text
4 9 2
3 5 7
8 1 6
```

## 3. 与热卜的差异（资料层）

| 项 | 易世家（本站） | 热卜 App 实测痕迹 |
|----|----------------|-------------------|
| 盘尺度 | 时家时盘为主 | 表单有 **年盘/时盘/刻盘** |
| 自选局 | 无（自动定局） | 可自选局数 |
| 三元 | 程序简化 5 日一元 | 服务端规则，需抓包对齐 |
| 结果增强 | MVP 无移星换斗着色等 | 有入墓/击刑/门迫等 UI |
| 计算位置 | 纯前端 | 服务端 PHP |

结论：本站 **不调热卜云端**；字段形态对齐，数值以易世家规格 + 黄金样例为准，热卜仅作交叉参考。

## 5. 冒烟样例

`2024-06-01 09:00` Asia/Shanghai，拆补，非真太阳：

- 应能排出：阴阳遁、局数、三元、旬首、值符、值使、九宫 9 格  
- 参考实现（Python）摘要示例：阳遁、小满段、下元、局数与符使因节气库精度可能与 App 差 1 档——**以同输入对照 App 锁定**

对照清单：

1. 阴阳遁 + 局数 + 三元  
2. 四柱（尤其时柱）  
3. 旬首 + 值符星 + 值使门  
4. 九宫地盘干 / 天盘干 / 星 / 门 / 神  
5. 马星宫、空亡宫
